<objective>
Turn the topic page into a linear, app-like guided flow: the reader meets Happi and an intro, then advances one section at a time (each fact, then the self-check, then the tips, then the balance, then — only last — the "Weiter geht's" topic cards) via a big "Weiter" button. The self-check becomes a gated mini-quiz: a big Start button ("Los geht's!"), questions one at a time, each answer revealing Happi's reflection instantly, and a "Weiter" that advances to the next question and finally to the tips.

Purpose: make the existing reference topic feel like a guided journey instead of a long scroll, and make the one-question self-check an actual linear experience (locked decisions 1–3, 2026-10-01). This is an enhancement over already-shipped markup — no architecture changes.

Output: an upgraded `src/js/app.js` stepper engine (with quiz gating), step markers in `src/themen.njk`, stepper/button styles in `src/css/site.css`, two new calibrated questions in `src/_data/topics.json`, and a "Stepper & Knöpfe" section in `docs/stimme-und-stil.md`.

**Hard boundaries (locked):**
- Progressive enhancement is mandatory: the no-JS page must remain exactly today's full scrollable page. All hiding/stepping is applied at runtime by app.js; no CSS rule may hide a `[data-step]` by default.
- Zero data collection: stepper and quiz state live in memory only. No persistence, no cookies, no network calls anywhere in app.js.
- All copy (buttons, progress, quiz-gate) follows `docs/stimme-und-stil.md`: no imperatives, no judgment/praise of answers, no scoring.
- Buttons are ≥48px tap targets and use the existing design tokens (ginger accent, cream, cocoa); light theme only; zero third-party requests.
</objective>
